<summary><h2>Vision AI Projects</h2></summary>

This section contains practical computer vision projects involving real-time detection, recognition, tracking, and image analysis using Python and deep learning frameworks.

### [1. Drowsy Driving Prevention System](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_01)

A real-time system that uses facial landmarks and Eye Aspect Ratio (EAR) to detect driver drowsiness, triggering alarms and visual alerts.

### [2. Real-Time Open-Vocabulary Object Detection](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_02)

Implements YOLO-World to detect objects specified through user-defined text prompts in real time, including a web-based interface.

### [3. Human Pose Estimation](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_03)

Uses YOLOv8-pose for real-time keypoint detection, dataset generation, and action classification (e.g., sitting vs. standing) using XGBoost.

### [4. Age & Gender Recognition](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_04)

Estimates age and gender from facial images using a WideResNet model pre-trained on the IMDB-WIKI dataset, with real-time webcam support.

### [5. Object Tracking Systems](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_05)

Implements real-time object detection and tracking using YOLO and BoT-SORT, supporting object identification and tracking across video frames.

### [6. Road Segmentation & Object Detection](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_06)

Combines YOLOv8 object detection with OpenVINO-based road segmentation for Advanced Driver Assistance System (ADAS) applications.

### [7. Korean License Plate Recognition](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_07)

Detects and recognizes Korean vehicle license plates using YOLO-based object detection and OCR techniques.

### [8. Three-Dimensional Computer Vision](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_08)

Explores 3D object detection and depth estimation, including Bird's Eye View (BEV) visualization for spatial analysis.

<summary><h2>Vision AI 프로젝트</h2></summary>

Python과 딥러닝 프레임워크를 활용하여 실시간 객체 탐지, 인식, 추적 및 영상 분석 기능을 구현한 프로젝트입니다.

### [1. 졸음운전 방지 시스템](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_01)

얼굴 랜드마크와 눈 종횡비(EAR)를 기반으로 운전자의 졸음 상태를 실시간 감지하고, 경고음 및 시각적 알림을 제공하는 시스템입니다.

### [2. 실시간 개방형 어휘 객체 탐지](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_02)

YOLO-World를 활용하여 사용자가 입력한 텍스트 프롬프트에 해당하는 객체를 실시간으로 탐지하며, 웹 기반 인터페이스를 포함합니다.

### [3. 인간 자세 추정](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_03)

YOLOv8-pose를 이용하여 신체 키포인트를 실시간으로 추출하고, 데이터셋 생성 및 XGBoost 기반 행동 분류를 수행하는 프로젝트입니다.

### [4. 연령 및 성별 인식](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_04)

IMDB-WIKI 데이터셋으로 사전 학습된 WideResNet 모델을 기반으로 웹캠 영상에서 얼굴의 연령과 성별을 실시간으로 추정하는 시스템입니다.

### [5. 객체 추적 시스템](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_05)

YOLO와 BoT-SORT를 활용하여 영상 속 객체를 실시간으로 탐지하고, 객체 식별 및 프레임 간 추적 기능을 구현한 프로젝트입니다.

### [6. 도로 영역 분할 및 객체 탐지](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_06)

YOLOv8 객체 탐지와 OpenVINO 기반 도로 영역 분할 기술을 결합하여 첨단 운전자 보조 시스템(ADAS)에 활용할 수 있는 기능을 구현했습니다.

### [7. 한국 차량 번호판 인식](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_07)

YOLO 기반 객체 탐지와 OCR 기술을 활용하여 차량 번호판을 검출하고, 번호판에 포함된 문자를 인식하는 시스템입니다.

### [8. 3차원 컴퓨터 비전](https://github.com/LutetiumCalciumLee/Studying_Computer_Vision/tree/Project_08)

3차원 객체 탐지 및 깊이 추정 기술을 활용하고, 조감도(Bird's Eye View, BEV) 시각화를 통해 객체의 공간적 정보를 분석하는 프로젝트입니다.
